# 💻 Technical Domain Concepts & Interview Grounding

## Domain Competency Areas

### 1. Software Engineering & Architecture
- **Data Structures & Algorithms:** Time/space complexity (Big-O), trees, graphs, hash tables, dynamic programming.
- **System Design:** Distributed systems, microservices, CAP theorem, load balancing, caching strategies (Redis/Memcached), message brokers (Kafka/RabbitMQ).
- **Database Engineering:** SQL vs. NoSQL, ACID transactions, indexing (B-Tree/GIN/BRIN), query optimization, partitioning, replication.

### 2. AI, Machine Learning & Data Science
- **Model Lifecycle:** Training, validation, hyperparameter tuning, loss functions, regularization.
- **Deep Learning & LLMs:** Transformer architecture, self-attention, tokenization, fine-tuning (LoRA/QLoRA), RAG systems, vector embeddings.
- **Evaluation Metrics:** Precision, Recall, F1-score, ROC-AUC, BLEU, ROUGE, perplexity.

### 3. Frontend & Full-Stack Engineering
- **Modern Web Architecture:** React internals (Virtual DOM, Fiber reconciliation, Hooks, State Management), SSR/SSG.
- **Performance & Security:** Core Web Vitals, tree-shaking, lazy loading, CORS, XSS, CSRF, JWT authentication.

### 4. Cloud & DevOps
- **Containerization & Orchestration:** Docker, Kubernetes (Pods, Deployments, Ingress).
- **CI/CD & Infrastructure:** Automated test pipelines, Blue-Green deployments, Terraform, Cloud IAM security principles.
